# 담당 업무

## API

- FastAPI 요청·응답 DTO와 공통 엔드포인트 설계
- 역할 지시문, 입력, 응답 스키마를 조합하는 메타 프롬프트 구성
- 로컬 Ollama 비동기 호출과 모델 선택
- JSON 전용 응답 파싱과 최대 3회 재시도
- 성공·실패·처리시간 기록용 SQLite 로그

## 데이터 처리

- HTML과 제어문자 제거
- Base64 이미지 제거
- 입력 길이 제한과 공백 정규화
- 엑셀 기반 VOC 일괄 요청과 결과 수집
- 건별 체크포인트, 완료 건 건너뛰기와 실패 격리를 적용한 재실행 흐름
- 원본 데이터의 불필요한 태그와 빈 데이터 정리

## 평가

- 사람이 채점한 200건과 네 가지 프롬프트 결과 비교
- Pearson, Spearman, Bias, MAE, RMSE, QWK 계산
- P0~P3 등급 정확도와 Critical 재현율 비교
- 과소평가와 과대평가 사례를 나눠 프롬프트 수정
- V3를 정확도·안정성 균형안으로 선정

공개 저장소에서는 실제 업무 데이터와 프롬프트를 제거하고, 같은 구조를 테스트 가능한 코드로 다시 작성했습니다.
