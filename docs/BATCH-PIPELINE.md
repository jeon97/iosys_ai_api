# VOC 일괄 평가 파이프라인

프롬프트 비교에서는 같은 VOC 묶음을 여러 프롬프트로 반복 평가했습니다. 중간 실패 때문에 전체 결과를 버리지 않도록 건별 실행, 체크포인트와 오류 격리를 적용했습니다.

## 처리 흐름

1. 레코드 ID와 입력을 정제합니다.
2. 이미 성공한 레코드는 체크포인트에서 확인해 건너뜁니다.
3. API 호출 결과를 건별로 저장합니다.
4. 실패한 레코드는 오류 유형만 기록하고 다음 건을 계속 처리합니다.
5. 실행 종료 후 성공·건너뜀·실패 건수를 비교합니다.

[app/batch.py](../app/batch.py)는 이 흐름을 외부 라이브러리 없이 재작성한 예제입니다. 실제 VOC 원문, 프롬프트와 결과 파일은 공개하지 않습니다.
